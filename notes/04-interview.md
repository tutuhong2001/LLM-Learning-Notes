## 演示顺序

1. 打开 README 的流程图，用 20 秒说明“学习笔记 → 检索 → 带来源问答”。
2. 运行 `python -m ai_toolkit search "LoRA 为什么能减少训练参数？"`，展示文档来源和排序。
3. 用同一个问题加 `--backend semantic`，解释词频匹配与向量相似度的区别。
4. 运行 `python -m ai_toolkit ask "RAG 与微调有什么区别？" --dry-run`，指出传给模型的资料与引用约定。有自己的服务配置后可以去掉 `--dry-run`。
5. 展示评估报告，解释 Recall@k 与 MRR@k，再指出小题集和拒答能力的局限。

## 常见追问

**为什么不用向量数据库？** 当前只有十篇短文，内存精确检索更简单。数据规模增长后，需要持久化、更新与元数据过滤时再引入。

**为什么不默认认为向量检索更好？** 专业词、错误码等精确匹配可能更适合词法检索；语义模型也会误匹配。要在同一题集上比较。

**有引用就不会幻觉吗？** 不会。引用格式检查只检查编号是否合法，需要继续核对结论是否被资料支持。

**怎样继续改进？** 先采集真实失败问题，再决定是否需要混合检索、重排、长文档分块或更好的拒答判断。
