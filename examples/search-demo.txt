# 微调与 LoRA

微调使用训练数据更新模型参数，适合调整输出风格、任务行为或特定任务表现。LoRA 冻结原有权重，只训练低秩适配参数，能够减少可训练参数量和优化器状态开销。

RAG 通过外部资料补充知识，微调则改变模型参数。频繁更新的事实知识常先考虑 RAG；稳定的格式或任务行为可以考虑微调。二者并不是互斥方案。

微调需要训练集与独立验证集，还要关注过拟合、数据许可与训练成本。本项目仅讲解微调概念，没有实现 LoRA 训练，不能以本项目宣称完成过微调实验。

# 文档切分与上下文长度

长文档需要切成较小片段。片段过大容易带入无关信息，过小则可能丢失完整语义。可以按标题、段落或 token 数切分，并保留少量重叠以减少边界信息丢失。

每个片段应保存文档来源与片段编号，方便引用和回溯。模型的长度限制通常以 token 计，不等于字符数；编码器可能截断超长输入，生成模型也有上下文窗口限制。

本项目使用人工整理的短 Markdown 文件，每个文件是一个检索单元，没有实现通用长文档切分器。加入 PDF 或长文章前，应先做解析、切分与 token 长度检查。
