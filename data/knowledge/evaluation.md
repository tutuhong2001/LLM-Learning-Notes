# 检索评估：Hit Rate、Recall 与 MRR

评估集包含 query 与 relevant_ids，后者是人工标注的相关文档 ID 集合。Hit Rate@k 表示前 k 个结果中至少命中一篇相关文档的问题占比。

Recall@k 先计算每个问题命中的相关文档数除以该问题全部相关文档数，再对所有问题取平均。MRR@k 取首个相关结果的排名倒数，未命中记为 0，再取平均。

只有一个相关文档时，Hit Rate 与 Recall 数值相同；有多个相关文档时，两者可以不同。检索命中不代表回答正确，还需人工或独立评估检查事实支持、引用准确性和拒答表现。小型自建题集只用于回归验证，不是通用能力排行榜。
